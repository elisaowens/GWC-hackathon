{# _body.html - the anatomical model. It is an SVG: a picture made of shapes, drawn with code. It has two layers: 1. "silhouette" the grey body outline (always visible) 2. "regions" invisible red shapes, one per body area. When a region gets the CSS class "highlight", it appears and pulses. Each region has: data-region its name. This MUST match "region" in data.py. data-view a zoomed-in box (x y width height) used by the mini picture in the hover pop-ups on the Test Results page. The drawing is 220 wide and 470 tall. Point (0,0) is the top-left corner. LEFT/RIGHT NOTE: like in a doctor's chart, the patient's RIGHT side is on the viewer's LEFT. So "right-wrist" is drawn on the left of the picture. This file starts with an underscore because it is not a page. It is a piece that other templates include with {% include "_body.html" %}. #}
